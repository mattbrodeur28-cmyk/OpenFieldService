# API contract map

The standalone listener serves all routes below. All normal API requests need the
session cookie. Mutations require `X-Requested-With: OpenFieldService`. JSON errors
use an `error` string; status codes distinguish invalid input (400), missing login
(401), permission denial (403), unavailable resource (404), stale/conflict (409)
and provider/server failure (5xx). Some feature handlers return more context.
Do not infer complete enterprise API stability from the existing contracts.

| API family | Contract / owning implementation |
| --- | --- |
| Service records | `/api/openapi.json`, generated by `src/server/index.ts`; README endpoint table |
| Dispatcher | `/api/dispatch/*`, `src/server/dispatch`; [contract and scheduling rules](dispatcher.md) |
| Session/setup/login/logout/password/profile | `/api/auth/*`, `src/server/auth.mjs`; [accounts](../../deploy/ACCOUNTS.md) |
| Users, temporary resets, teams/members/messages | `/api/auth/users`, `/api/auth/teams`; `auth.mjs`; [permissions](../security/permissions.md) |
| AI, conversations, Knowledge, settings | `/api/workspace/*`, `src/server/workspace.mjs`; [workspace](../../deploy/WORKSPACE.md) |
| Builder files/proposals/revision threads/export | `/api/workspace/builder/*`, `workspace.mjs`; workspace guide |
| OAuth configuration/connect/callback/read/disconnect | `/api/integrations/*`, `src/server/integrations.mjs`; [integration contracts](../../deploy/INTEGRATIONS.md) |
| Optional published company | `/api/public/company`; workspace service; private until explicitly published |
| Operational health | `/healthz`; Node entry point; service DB connectivity only |

Service IDs and relationship IDs are UUID strings; display labels are separate.
Builder checks source hashes and returns stale information rather than overwriting
changed source. Team reads return up to 100 recent messages; search is client-side
within that set. HR roster access does not automatically return conversations.
OAuth callbacks are session-independent only with valid one-use user-bound state.

Workspace/auth/integration contracts remain source-defined and behavior-tested;
complete generated OpenAPI and a compatibility/deprecation policy are M2 work.
Read the owning handler and its tests before changing request/response behavior.
