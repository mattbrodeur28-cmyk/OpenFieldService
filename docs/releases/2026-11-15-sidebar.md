# Sidebar disclosure and compact rail repair

Sales, Fleet, HR, and Finance now use one full-width disclosure button. Clicking
its icon, label, whitespace, or chevron performs the same toggle; Enter/Space use
the native button behavior. The existing Overview child remains the route to the
module landing page. Field Service already uses a full-row disclosure.

In the compact rail, those modules hide their text-only child links instead of
leaving blank clickable rows. Their module icons navigate to Overview; expanding
the rail restores the saved per-user section state. Role filtering is unchanged. App headers use the regular sidebar active-route
highlight, rather than a permanent gray background. Field Service is highlighted
when one of its native pages (including equipment and legacy route aliases) is
current; merely expanding an inactive section does not mark it as selected.
The compact account button retains its initials for mouse and touch devices,
fits the rail, and has an explicit profile/settings accessible name. Other compact
navigation links also retain explicit names independent of hidden label text.

Validation: TypeScript, production build, and whitespace checks. This is a local
UI repair with no API, database, role, or migration changes. Browser interaction
qualification remains pending because automatic approval review previously hit an
account usage limit, and the latest browser inventory reports its access host
unavailable. The rebuilt local demo responds HTTP 200; no browser success is
inferred from that response or the build.
